# Instant Learn

**财务自由 · DSH 插件与投资学习资料库。**

这是一个 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai) 插件：在侧栏提供书单、纪录片、美股博主、论坛与 Web3 工具索引，支持搜索、收藏、学习进度和笔记；同时注册 `/财务自由` skill。

## 内容

- 16 本投资与理财书
- 16 部金融纪录片
- 23 个美股 YouTuber
- 5 个美股论坛与工具站
- 11 组 Web3 / 币圈工具

## 使用

安装、开发与数据结构说明见 [`dsh-finance/README.md`](./dsh-finance/README.md)。
