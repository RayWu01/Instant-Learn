# Instant Learn

> 学得快一点，把 AI 真正用起来。

这个仓库收录两组轻量、可直接打开或安装的学习材料：

## 内容

### `ai-at-work/`

一份单文件 HTML 演示：**《把 AI 用成同事》**。内容围绕工作中使用 AI 的核心心法、提示词方法、常见场景、协作流程与安全边界展开，并带有演示与排练功能。

打开方式：

```bash
open ai-at-work/ppt/index.html
```

演示中的字体、图标和动效依赖 Google Fonts、Lucide 与 Motion 的在线资源。

### `dsh-finance/`

一个 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai) 插件：**财务自由 · 投资资料库**。在 DSH 侧栏提供书单、纪录片、美股博主、论坛与 Web3 工具索引，支持搜索、收藏、进度和笔记；同时注册 `/财务自由` skill。

安装、开发与数据结构说明见 [`dsh-finance/README.md`](./dsh-finance/README.md)。
